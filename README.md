# Cancer Transcriptomics Analysis — TCGA & TANRIC

## Overview
This repository contains scripts and pipelines for transcriptomic 
analysis of cancer datasets, focusing on long non-coding RNA (lncRNA) 
expression patterns across multiple cancer types.

Data sourced from publicly available databases including TCGA 
(The Cancer Genome Atlas) and TANRIC (The Atlas of Noncoding RNAs 
in Cancer).

## Cancer Types Analysed
Multiple solid tumour types available through TCGA/TANRIC

## Tools & Languages
- R (survival analysis, differential expression)
- Python (data processing and visualisation)
- TANRIC portal
- TCGA/GDC data portal
- NCBI, GeneCards, Biotools, ENCORI

## Status
Repository actively updated as analysis pipelines are developed.
